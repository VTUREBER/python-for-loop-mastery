# Python For Loop Mastery (for-loop-101) 🐍

ยินดีต้อนรับสู่โปรเจกต์ฝึกฝนการเขียนโปรแกรมด้วยภาษา Python โดยเน้นการใช้งาน **For Loop** เป็นหลัก! ชุดแบบฝึกหัดนี้ออกแบบมาเพื่อให้คุณเข้าใจกลไกการทำงานของลูป การวนซ้ำ และการจัดการข้อมูลในรูปแบบต่างๆ

## 🚀 วิธีการเริ่มต้น
1. **Fork** รีโพสิทอรีนี้ไปยังบัญชี GitHub ของคุณ
2. **Clone** ไปยังเครื่องคอมพิวเตอร์ของคุณ:
   ```bash
   git clone https://github.com/[your-github-username]/python-for-loop-mastery.git
   ```
3. เข้าไปยังโฟลเดอร์โปรเจกต์:
   ```bash
   cd python-for-loop-mastery
   ```

## 📝 ขั้นตอนการทำแบบฝึกหัด
1. เปิดไฟล์แบบฝึกหัดที่ต้องการทำ (เช่น `ex01_sum_range.py`)
2. อ่านคำอธิบาย (Docstring) ในไฟล์ให้เข้าใจ
3. เขียนโค้ดในส่วนที่กำหนด:
   ```python
   # --- เริ่มเขียนโค้ดด้านล่างนี้ ---
   # เขียนโค้ดของคุณตรงนี้
   # --- สิ้นสุดการเขียนโค้ด ---
   ```
4. บันทึกไฟล์

## ✅ วิธีการตรวจคำตอบ
คุณสามารถใช้สคริปต์ตรวจคำตอบอัตโนมัติได้โดยรันคำสั่ง:
```bash
python3 check_solution.py
```
สคริปต์จะแสดงผลลัพธ์ว่าคุณผ่านแต่ละข้อหรือไม่ พร้อมทั้งแสดงคะแนนรวม
